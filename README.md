# ネットワークスペシャリスト試験 知識カード

情報処理技術者試験「ネットワークスペシャリスト（NW）」の科目B（B-1・B-2）対策。
過去問の長文を読み込まなくても、**この設問を解くにはこの知識が要る** というものを、過去問の解答から抜き出してカードにしている。

**カードを見る** → https://asasuzu.github.io/network-specialist/

## カードの3段階

| 段階 | 中身 |
|---|---|
| 基礎 | その技術は何をするものか |
| 知識 | 試験で問われる知識（用語・数値・動作） |
| 過去問 | 実際の設問と、その答え方の「型」 |

過去問カードには、本文を読む必要の度合いを付けている。

- ◎ 本文を読まなくても解ける
- ○ 本文を少し確認すれば解ける
- △ 本文・図の読み取りが必要

## 構成

- `cards/` … カードの元データ（Markdown）。分野ごとに1ファイル
- `cards/manifest.json` … ページに表示するファイルの一覧
- `index.html`, `assets/` … カードを表示するページ（GitHub Pages）
- `past-exams/` … 年度別の過去問PDF（問題・解答例）。PDFはGit管理外（IPAサイトから取得）

## カードの書き方

```markdown
## グループ名

### 問い（カードの表）
- 段階: 過去問
- 出典: R7 午後Ⅰ 問1 設問1(2)
- 本文: ◎
- 状況: 本文を読まなくても場面がわかる2〜3文の説明

答え（Markdown）

> こう聞かれたら、こう答える（「解き方の型」として表示される）
```

`段階` は必須。`出典` と `本文` は過去問由来のカードに付ける。
問題固有の機器名（R10 など）が出てくるカードには、必ず `状況` を付ける。問いの文章では機器名を使わず、役割（「交換するルータ」など）で書く。
問いはカード単体で成り立つように書く。問題の状況を前提にした問い（「なぜ分けておく？」）や、問題の中だけの呼び名（「機能2」）は使わない。答えが「〇〇とは」の説明から始まるなら、問いにも「〇〇とは？」を入れる。
元の試験の空欄記号（［g］、a：、ア〜エ など）は使わず、意味で聞いて意味で答える。出典の行（設問1(1)a など）だけは記号のまま残す。

## 出典の書き方

- 年度は和暦（R7 = 令和7年度春期）
- 過去問は当時の呼び方のまま **午後Ⅰ**・**午後Ⅱ** と書く（今の科目B-1・B-2にあたる）

## 作成済みの範囲

令和3〜7年度の午後Ⅰ・午後Ⅱ、全25問の全設問（602枚：基礎86・知識150・過去問366）。

| 分野 | ファイル |
|---|---|
| ルーティング・冗長化 | `routing.md` |
| VPN・WAN・クラウド接続 | `vpn.md` |
| Web・DNS・負荷分散 | `web.md` |
| 認証 | `auth.md` |
| セキュリティ・プロキシ | `proxy-security.md` |
| IP・LANの基盤 | `lan-ip.md` |
| 監視・運用 | `ops.md` |
| 無線LAN | `wireless.md` |
| データセンター・仮想化 | `dc.md` |
| その他のテーマ（出題が少ないもの） | `other.md` |
| ポート番号・プロトコル番号 | `ports.md` |

各カードの答えは IPA の解答例と照合済み。R6 午後Ⅱ 問2 設問5 は IPA が「不備により設問が成立しない」としたため、過去問カードはない。

過去問の出典：独立行政法人情報処理推進機構 ネットワークスペシャリスト試験 問題・解答例。カードの解説は独自に作成したもの。
