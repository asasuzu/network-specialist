# ネットワークスペシャリスト試験 知識カード

情報処理技術者試験「ネットワークスペシャリスト（NW）」の科目B（B-1・B-2）対策。
過去問の長文を読み込まなくても、**この設問を解くにはこの知識が要る** というものを、過去問の解答から抜き出してカードにしている。

**カードを見る** → https://asasuzu.github.io/network-specialist/

## カードの3段階

| 段階 | 中身 |
|---|---|
| 基礎 | その技術は何をするものか |
| 知識 | 試験で問われる知識（用語・数値・動作） |
| 過去問 | 実際の設問と、その答え方の「型」 |

過去問カードには、本文を読む必要の度合いを付けている。

- ◎ 本文を読まなくても解ける
- ○ 本文を少し確認すれば解ける
- △ 本文・図の読み取りが必要

## 構成

- `cards/` … カードの元データ（Markdown）。分野ごとに1ファイル
- `cards/manifest.json` … ページに表示するファイルの一覧
- `index.html`, `assets/` … カードを表示するページ（GitHub Pages）
- `past-exams/` … 年度別の過去問PDF（問題・解答例）。PDFはGit管理外（IPAサイトから取得）

## カードの書き方

```markdown
## グループ名

### 問い（カードの表）
- 段階: 過去問
- 出典: R7 午後Ⅰ 問1 設問1(2)
- 本文: ◎

答え（Markdown）

> こう聞かれたら、こう答える（「解き方の型」として表示される）
```

`段階` は必須。`出典` と `本文` は過去問由来のカードに付ける。

## 出典の書き方

- 年度は和暦（R7 = 令和7年度春期）
- 過去問は当時の呼び方のまま **午後Ⅰ**・**午後Ⅱ** と書く（今の科目B-1・B-2にあたる）

## 作成済みの範囲

- 令和7年度 午後Ⅰ 問1〜問3

---

過去問の出典：独立行政法人情報処理推進機構 ネットワークスペシャリスト試験 問題・解答例。カードの解説は独自に作成したもの。
